## 3 · Bugs found on the device, fixed test-first, re-verified there

1. **The A–Z index jumped to the wrong letter** (Z → A, then Z → O).
   React Native's `locationY` is relative to the view under the finger (the
   letter), and the strip stretches with the letters centred. Fixed in
   `f77c821`; device: Z → Z, # → #. Same commit: a nameless imported card's
   row showed its number twice.
2. **Import from the phone failed on every Android phone.** Android's native
   `ContactField` has no `birthday` (the TypeScript types do); asking for it
   rejected the whole read. Jest mocks the native module and could not see
   it. Fixed in `f90df73` (Android asks for `dates`); device: 2 added, 1
   already there.
3. **A vCard shared with a generic type and no name went to Pages.** The
   bridge now reads the first bytes of such a file. Fixed in `6d48a38`;
   device: the form filled in.
