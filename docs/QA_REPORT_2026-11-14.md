## Second slot (2026-11-14, morning): release build, PIN layout, soak

- **Android release builds were failing (BLOCKER, fixed).** A local
  `assembleRelease` stopped at `lintVitalRelease`: five `ExtraTranslation`
  errors, because `locales/ios-fr.json` (8b58194, 2026-11-12) put the iOS
  `NS…UsageDescription` sentences at the top level and Expo writes those into
  Android's `values-b+fr/strings.xml`. Every Android store build since would
  have failed. The sentences now sit under `"ios"` (`89e964e`, merged
  `de6c82e`, test `localesConfig.test.ts`); the release build then passed.
- **"Forgot your PIN?" under the dots** (`41e521b`, merged `f9f5887`): on the
  device the link and the whole keypad (key 0 above the gesture bar) fit at
  360×640, 360×780, 411×731 and 411×914 dp. Note: the first night's "360/411"
  captures were 1.6-ratio screens (360×576), shorter than any common phone.
- **Cold-start `.vcf` share on a RELEASE build: PASS.** App stopped, Files →
  one `.vcf` → MultiMagic: the filled new-contact form. The dev build's
  "1 file · 0 B" was the dev launcher's hop, now measured, not inferred; the
  "Couldn't read this file" guard stays.
- **Fabric soak, debug build, overlay OFF: 1 crash in 20 launches** (launch 9,
  Pages tile): the same SIGSEGV in `MountingCoordinator::pullTransaction`,
  12 s after start, same `libreactnative` build. The perf-overlay guess is
  refuted; the cause is still NOT known.
